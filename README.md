-♙ How to Run ♙-

Unzip the project folder.

Open cs230_Final.sln with Visual Studio.

Set the build mode to either Debug or Release, and set the platform to x64.

If the file path contains Korean characters, it's recommended to move the project to a different location without them.

-♗ Game Description ♗-
Use the left or right arrow keys to move the player.
If you reach a seat before being spotted by a passenger (i.e., before stepping in front of their seat), you successfully steal food and gain 20 points.
If you bump into an obstacle in the aisle or get caught by a passenger, you lose 10 points.
As your score increases, you’ll begin to make different types of sandwiches.

Controls -
Left Arrow – Move Left
Right Arrow – Move Right
ESC – Exit

Good luck!
